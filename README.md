# nitishjeebun.github.io

Personal studio site for independent iOS apps.

## Pages

- `/` studio home
- `/apps/` catalog
- `/snapordina/` and `/qrartify/` product landings
- `/privacy/` and `/support/` shared studio pages
- Per-app `/[app]/privacy/` and `/[app]/support/`

## Add a new app

1. Add an entry to `assets/js/apps.js`.
2. Copy `qrartify/` to a new slug.
3. Replace copy, screenshots, and status.
4. Add the URLs to `sitemap.xml` and the footer in `assets/js/site.js`.

Set `storeUrl` in `assets/js/apps.js` when an app is on the App Store. QRArtify is live at https://apps.apple.com/us/app/qrartify-qr-code-maker/id6755909289
