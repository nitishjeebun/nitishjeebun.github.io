Support

Start with the app pages. If you still need help, send a request through the form. There is no public email on this site.

Where do I find app-specific help?

SnapOrdina support and QRArtify support cover permissions, scanning, and known limits.

How are requests handled?

The form opens a GitHub issue with the details you entered. That is the support desk for this studio. Include the app name, device model, and system version.

Do I need a GitHub account?

Yes, to submit the request. The form never asks for an email address on this site and never displays one.
